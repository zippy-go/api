# CLAUDE.md

Public repository holding the ZippyGo API contract: OpenAPI document, event
schemas, error catalog, generated SDKs and the developer portal. Read this
before changing anything.

## Structure

- `openapi/openapi.yaml` is the root document; path items live in
  `openapi/paths/<domain>/<resource>.yaml`, schemas in
  `openapi/components/schemas/<domain>/<Name>.yaml` (one schema per file,
  PascalCase names, snake_case properties, description and examples on
  every schema). Register every schema under `components.schemas`.
- `events/` holds `envelope.schema.json`, `catalog.yaml`, payload schemas
  and one validated example per event version.
- `errors/catalog.yaml` lists every error code; codes are never renamed.
- `sdks/typescript/src` is generated by `@hey-api/openapi-ts` from
  `dist/openapi.json` and is committed. Never edit it by hand.
- `portal/` is the VitePress site (`vitepress build portal`); the reference
  page embeds Scalar and loads `/openapi.json`, which `pnpm portal:sync`
  copies from `dist/`. `events.md`, `changelog.md` and `versioning.md`
  include the root Markdown files; keep those files free of relative links.

## Commands

Prefix shell commands with `source ~/.nvm/nvm.sh && nvm use 26.11.1 >/dev/null &&`
when the shell does not pick up Node 26 by itself.

- `pnpm check` runs everything CI runs: lint, bundle, gen:ts, typecheck,
  events:check, portal:build. Run it before every commit.
- `pnpm lint` lints the sources with Redocly, bundles, then lints the
  bundle with Spectral (Spectral cannot validate OpenAPI 3.1 path-item
  `$ref`s to external files, so it runs on the bundle).
- `pnpm bundle && pnpm gen:ts` regenerates the SDK; commit the result.
- `pnpm portal:dev` serves the portal locally.

## Rules

- Latest stable versions only, verified against the registry on the day
  (`npm view <pkg> version`); pin exact versions. Exception recorded here:
  `typescript` stays on the newest 6.x because `@hey-api/openapi-ts` needs
  the TypeScript compiler API, which the `typescript` 7 package no longer
  exports. Re-check when upgrading `@hey-api/openapi-ts`.
- This repository is public: no secrets, no internal hostnames or links,
  no customer or employee data, neutral wording. Hosts in the contract are
  placeholders on the reserved `.example` domain.
- Changes within a major version are additive only (see VERSIONING.md);
  CI runs `oasdiff` against `main` and fails on breaking changes.
- Every change to the contract gets a line in `CHANGELOG.md` under
  *Unreleased*.
- Vocabulary: **partner** is the supply-side tenant (an organisation or an
  individual that sells products, sells services or provides fleet
  capacity) and **agent** is the person (later, machine) that executes
  tasks. Never use merchant, driver or organisation as the primary term.
  The AI workers that write code are always "coding agents", so a bare
  "agent" means the delivery agent.
- Keep the portal on the default VitePress theme; add pages to the sidebar
  in `portal/.vitepress/config.mts`.
- Do not add a licence file, product copy or sample data beyond minimal
  placeholders; the founder decides those.
- Commit messages end with
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
